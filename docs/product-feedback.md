# Hackathon product feedback draft

This is a draft for the final submission; update it to reflect actual use and judging-time testing.

## Alexa+ simulated experience

NEST uses the hackathon's simulated Alexa+ web experience path. The assistant calls app-level tools for routine lookup, event history, and caregiver check-ins. Showing each structured tool result makes the assistant's data path visible. The offline mock keeps the demo repeatable and avoids requiring credentials.

## Ring developer resources

The Ring documentation was reviewed for endpoint and security boundaries, but no Ring API is called by this prototype. The supplied NEST build spec explicitly keeps live Ring integration out of scope. All device-like events are generated by the local simulator and labeled as simulated.

## Amazon Bedrock

Bedrock has not been integrated or exercised in this build. The AWS Builder challenge should not be selected unless a Bedrock Runtime tool-calling provider is implemented, configured with an account, and shown working in the demo.
