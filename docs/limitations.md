# Limitations

- NEST is a simulated prototype using fictional profiles, not a care or monitoring product.
- No Ring, Alexa+, Bedrock, smart-home device, notification, video, audio capture, or emergency-service integration is active.
- The AI is a deterministic mock and supports only a small set of intents.
- Authentication and caregiver-to-person authorization are not implemented. Do not use real personal or health data.
- Browser speech synthesis depends on the user's browser and operating system. Deafblind tactile interfaces are outside this prototype.
- The demo clock and event simulator do not reproduce a production scheduler, webhook delivery, or device event stream.
